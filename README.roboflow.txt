# PPE Dataset

This project uses the **Construction PPE Detection v1** dataset for the PPE-detection model.

- Classes: `boots`, `gloves`, `helmet`, `human`, `vest`
- Split sizes: 4,380 training images, 420 validation images, and 211 test images
- License: CC BY 4.0
- Source: [Roboflow Universe - Construction PPE Detection](https://universe.roboflow.com/roboflow-100/construction-ppe-detection)

The local dataset configuration is stored in `dataset_vest/data.yaml`.
